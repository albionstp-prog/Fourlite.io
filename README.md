# fourlite.com

Static one-page site for Fourlite, a London studio and incubator.

- `index.html`: the site (all styles and scripts inline)
- `404.html`: not-found page
- `favicon.svg`: browser tab icon
- `CNAME`: custom domain for GitHub Pages
- `.nojekyll`: tells GitHub Pages to serve files as-is

To update copy, edit `index.html` and commit. GitHub Pages republishes in about a minute.
